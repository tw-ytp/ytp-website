這份手冊給負責維護 www.tw-ytp.org 內容的同仁，不需要懂 GitHub，後台存檔就是上線。手冊只在後台左側「操作手冊」與邀請信附的 PDF 提供，不對外公開。管理員：author@tw-ytp.org。

## 1. 登入與第一次進入後台

1. 你會收到一封寄件者為 Pages CMS 的邀請信，標題類似「You've been invited to tw-ytp/ytp-website」。沒收到請先看垃圾郵件。
2. 點信裡的連結，或直接開 https://app.pagescms.org → 在下方 Email 欄位輸入你收到邀請的那個信箱、按 Continue with email → 收一封登入信 → 點信裡的登入連結。沒有密碼，每次登入都是收信點連結。
3. 進入後看到「Open a project」，點 `ytp-website` 右邊的 **Open**。
4. 左上角確認分支是 **main**（平常不要動它；切到其他分支存檔不會上線）。

![登入頁：同仁用下方 Email 欄位登入](/docs/manual/01-login.png)

![Open a project：點 ytp-website 右側的 Open](/docs/manual/02-open-project.png)

用電腦瀏覽器操作（Chrome、Edge、Safari 都可），手機可以看但不適合編輯。

## 2. 後台各區塊是什麼

左側選單分三群：

| 區塊 | 對應網站哪裡 | 誰會動 |
| --- | --- | --- |
| 最新消息 | /news/ 與首頁「最新消息」區 | 最常用：公告、晉級名單、活動回顧 |
| 學員故事 | /stories/（卡片式，有封面照） | 海外參訪心得、訪談 |
| 常見問題 | /program/faq/ | 報名季前檢視 |
| 歷屆成果（專題與黑客松作品） | /projects/ | 每屆成發後新增作品 |
| 備賽資源（解析／指南／影片） | /resources/solutions/ | 挑戰營後加題目解析 |
| 網站頁面（關於、計畫介紹、報名、規則、下載、備賽資源、青年圖靈++、English） | 各該頁的文字 | 只改文字；頁面不能新增或刪除。文字裡的 `{{season.edition}}` 這種大括號是「自動帶入當屆數字」的佔位，不要改掉 |
| 當屆賽季狀態 | 首頁主視覺的文案與按鈕、報名表單、簡章檔案 | 賽季換階段時改「目前階段」 |
| 影響力數字 | 首頁與關於頁的數字卡 | 每年更新一次 |
| 歷年考古題 | /resources/past-exams/ | 每年挑戰營後加兩筆（高中組／國中組） |
| 站台基本資料 | 頁尾聯絡信箱、社群連結、練習平台 | 很少動 |
| 進階：第二階段黑客松、青年圖靈++、歷屆三階段時程 | 活動頁與年度時間軸 | **請勿動**，欄位多且彼此關聯，有需要找管理員 |
| Media：活動照片、下載檔案、頁首橫幅 | 網站用到的圖片與 PDF | 見第 5 節 |
| 操作手冊 | 這份文件（不會出現在網站上） | 要改手冊內容時在這裡改；改完請管理員重新匯出 PDF |

![後台首頁：左側選單、左上角分支 main、右上 Add an entry](/docs/manual/03-dashboard-news-list.png)

列表頁右上角的 **Add an entry** 是新增；每一列右側的 **Edit** 是修改，「⋮」裡有 Delete（平常不用：還沒上線的請勾「草稿」，要下架的請勾「已下架」，見第 4 節；Delete 會永久刪除檔案）。

## 3. 新增一則最新消息（逐步）

1. 左側點「最新消息」→ 右上 **Add an entry**。
2. 填欄位：
    - 標題：網頁與首頁列表都顯示這個，建議 25 字內。
    - 日期：預設今天，列表依此排序，最新在上。
    - 類型：公告（一般）、活動回顧（辦完後的花絮）、通知（時效性短的提醒）。
    - 相關屆次：選填，填數字（如 11），該屆的挑戰營頁會列出這則。
    - 草稿：**先勾起來**（見第 4 節）。
    - 內文：選取文字會出現粗體、連結等格式工具；在新的一行輸入半形斜線 `/` 可插入標題、清單、圖片、表格。從 Word 或 Google Docs 貼過來會保留大部分格式。
3. 右上 **Save**。存檔後列表會多一列。
4. 約 2 分鐘後開預覽站 https://staging.ytp-website.pages.dev/news/ 看結果。

![編輯頁：草稿開關打開、右上 Save](/docs/manual/05-new-entry-filled.png)

![存檔成功：右下角出現 saved successfully](/docs/manual/05b-saved-toast.png)

網址是自動產生的（例如 /news/2026-10-27-1455/，日期加時間），不用管。存檔後不要改檔名（「⋮」→ Rename），改了網址就變，已分享出去的連結會壞。

## 4. 草稿、預覽、上稿、下架

每一筆內容都有兩個開關：「草稿」與「已下架」。另一個欄位「內容狀態」（正常／內容待補）跟上下稿無關：選「內容待補」只是在頁面加一個黃色提示，內容仍會上線。

| 開關 | 正式站 www.tw-ytp.org | 預覽站 staging.ytp-website.pages.dev | 什麼時候用 |
| --- | --- | --- | --- |
| 都不勾 | 上線 | 看得到 | 已上稿 |
| 草稿 | 看不到（沒有網址、不在列表、搜不到） | 看得到，頁首有黃色「草稿」橫幅 | 還沒寫完、等人確認 |
| 已下架 | 看不到 | 看不到 | 過時的消息、不再適用的 FAQ；檔案保留，要重新上架就取消勾選 |

標準流程：

1. 寫內容，勾草稿，Save。
2. 等 2 分鐘，開預覽站確認版面、錯字、連結。
3. 回後台 Edit，取消草稿，Save。
4. 等 2 分鐘，正式站上線。

下架：Edit → 勾「已下架」→ Save。內容還在，隨時可以再上，而且不會留在預覽站干擾。**不要用 Delete**，除非確定永久不要。

預覽站的網址可以傳給同事看，但不要對外公開（裡面有所有草稿）。

## 5. 上傳照片與 PDF

四種情形：

**內文裡的圖**（最新消息、學員故事、專題簡介）：在內文新的一行輸入半形斜線 `/`，選單選 Image → 進入 posts 資料夾 → Upload 選檔（或點選已有的圖）→ Select。圖會自動放進網站資料夾。選取文字時出現的小工具列是粗體、連結等格式，插圖不在那裡。

**學員故事封面照**：編輯頁有「封面照」欄位，點選後從媒體庫選圖或直接上傳（橫式為佳，卡片會裁成 3:2）。沒填就用色帶。

**各屆挑戰營相簿**：Media →「活動照片」→ 進入該屆的數字資料夾（沒有就用資料夾圖示新增，名稱就是屆數，如 `12`）→ Upload 一次可選多張。縮圖與頁面上的相簿會在建置時自動產生，約 2 分鐘後出現在該屆的挑戰營頁與首頁花絮。一次上傳建議 30 張以內，多分幾次。

**簡章、考古題等 PDF**：左側 Media →「下載檔案」→ Upload。上傳後到「歷年考古題」或「當屆賽季狀態」的檔案欄位點選該檔即可，不必自己貼路徑。

**要換掉已經放好的圖或 PDF**：先按欄位上的 ×（刪除），欄位會變回「選擇／上傳」按鈕，再選新檔。這是後台的設計，不是壞掉。

規則：

- 檔名用英數與連字號，不用中文、空格（例：`2026-camp-award.jpg`、`ytp-12-brochure.pdf`）。
- 照片不必先縮小：超過 1600px 的原圖建置時會自動縮。單檔仍請控制在 10MB 以內。
- 影片不上傳，放 YouTube 後貼連結。

## 6. 各區塊填寫要點速查

| 區塊 | 必填 | 要點 |
| --- | --- | --- |
| 最新消息 | 標題、日期、類型 | 見第 3 節 |
| 學員故事 | 標題、日期、作者 | 作者是學員本人且已同意刊登，可用全名；「參訪團」如「2025 矽谷」，同一團要打一模一樣才會歸在同一個篩選；封面照選填 |
| 常見問題 | 問題、受眾、區塊、順序 | 受眾決定出現在哪個頁籤；區塊是小標題（如「報名」）要與既有的一模一樣才會歸在一起；順序小的在前，插入中間就用 15、25 這種數字 |
| 歷屆成果 | 作品名稱、出處、屆次、年份 | 黑客松作品「活動編號」要填；名次 0 = 未得名；技術標籤從這 23 個選：AI、LLM 應用、機器學習、NLP、影像辨識、語音與音訊、區塊鏈、演算法與競程、資安、資料科學、推薦系統、聊天機器人、行動 App、網頁應用、桌面與工具、硬體與 IoT、遊戲、教育、醫療、金融、旅遊與地理、職涯與創業、社會與公益；**隊員姓名必須遮蔽** |
| 備賽資源 | 標題、日期、類型 | 影片類型要填 YouTube 網址 |
| 網站頁面 | 標題 | 只改文字。大括號佔位（如 `{{season.edition}}` 當屆、`{{season.nextYear}}` 下一年、`{{season.registration.close}}` 報名截止日、`{{site.email}}` 信箱）會自動換成數字，請保留；報名頁的兩個副標分別用於報名期間與非報名期間 |
| 當屆賽季狀態 | — | 只改「目前階段」、報名起訖日、報名表單連結、簡章檔案；「各階段」裡的代號勿改 |
| 影響力數字 | 數字、說明 | 數字是顯示文字，可含逗號（如 5,546） |
| 歷年考古題 | 年份、組別、階段 | 右上 Add an entry 新增；檔案從「下載檔案」選；留空會顯示「待上架」；網站自動依年份排序，不用管順序 |

## 7. 三條紅線

1. **學生姓名一律遮蔽**：王O明、歐陽O娟（複姓保留、名字第一字改大寫 O）。系統在上線前會掃描，出現全名整個網站都不會更新，直到修正。學員故事的作者是例外（本人同意刊登）。
2. **不貼學生個人社群、電話、學號**：GitHub 作品連結可以，個人 IG、FB 不行。
3. **進階三個區塊不要動**：那裡的欄位連動首頁時間軸與屆次頁，改錯會讓整站建置失敗。

## 8. 常見問題

**存檔了，正式站過了 5 分鐘還沒更新？** 依序確認：① 草稿是否還勾著；② 左上角分支是否為 main；③ 瀏覽器強制重新整理（Ctrl+Shift+R 或 ⌘+Shift+R）；④ 都不是就截圖給管理員，可能是建置失敗（通常是姓名未遮蔽或必填欄位空白）。

**存檔時出現紅字錯誤？** 通常是必填欄位沒填或日期格式不對，訊息會指出哪個欄位。

**找不到某一篇？** 列表右上角有搜尋框；列表預設依日期排序，老文章在下面。

**不小心改壞了？** 每次存檔都有紀錄，管理員可以退回任一版本，說一聲即可，不要自己再亂改。

**兩個人同時改同一篇？** 後存的會覆蓋先存的。同一篇請一次一個人改，不同篇不影響。

**要改首頁大標題、選單？** 這些不在後台，找管理員；關於、計畫介紹、報名、規則、下載、備賽資源、青年圖靈++、English 的文字在「網站頁面」可以改。

**登入信沒收到？** 看垃圾郵件；仍無，請管理員到 Collaborators 重送。
