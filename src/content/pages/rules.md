## 設備與場地規定

- 每組：筆記型電腦（有無線網卡）1 台、滑鼠 1 個、鍵盤 1 個。請避免音量過大的電競或機械式鍵盤。
- 禁止攜帶其他電子通訊器材進場；可交由主辦單位保管。
- 可帶書籍、手冊、紙本程式碼；不可帶外接硬碟、隨身碟、記憶卡等可讀寫設備。
- 競賽中只能與同隊隊員或工作人員交談。
- 嚴禁使用生成式 AI 工具。允許參考事先儲存在筆電內的題目與解答。

## 評測環境

- Linux + GNU Compiler Collection；提交、評審、計分都透過無線網路連到主辦單位的競賽系統。
- C（C11 / gcc）、C++（C++17 / g++）、Java（OpenJDK 1.8）、Python 3.10 或 Python 2.7。
- 檔案名稱須遵守命名規則；含特定 IDE 才能辨識的程式碼將無法通過評測。
