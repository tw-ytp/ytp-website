團隊因請假或線上課程需補看上課錄影，發現整理重點耗時，因此開發行動應用程式 SUMMAREASE，把課堂錄影自動整理成大綱，並可就內容與 AI 討論。實作以 Flutter 撰寫相容 iOS 與 Android 的介面，資料庫使用 Firebase 的 Authentication、Storage 與 Cloud Firestore；語音轉文字串接 OpenAI Whisper API，於雲端處理以降低對手機效能的要求，再由 ChatGPT API 整理文字並支援追問，另有 Email 分享功能。實測中化學與國文的摘要能抓到重點觀念與解題關鍵，數學則因無法讀取黑板算式而須搭配影片；使用者回饋約節省 50% 補課時間，並希望能支援 YouTube 連結與更多分享形式。上架至商店尚未完成，未來規劃結合影片畫面文字辨識、製作大綱影片並延伸應用至會議等場域。
