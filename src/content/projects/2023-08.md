該專題認為網路論壇的討論常被情緒性字眼佔據，逐則閱讀既耗時又可能影響情緒，因此開發議題事件分析器，於數秒內完成上千則留言的情緒分析。實作先以 Python 搭配 bs4 爬取網頁文章與留言，情緒分析比較 Hugging Face 上的 twitter-roberta-base-sentiment-latest、distilbert-base-multilingual-cased-sentiments-student 與 distilroberta-finetuned-financial-news-sentiment-analysis 三個模型，不支援中文者先以 opus-mt-zh-en 翻譯，超出輸入上限的長文則切割後依權重計算；介面以 HTML 與 JavaScript 呈現，並用 Flask 串接前後端。三者準確度分別為 53%、60% 與 33%，支援中文的 distilbert 模型較快且無翻譯失真問題。團隊指出系統對硬體有一定需求，也難以平衡功能性與操作門檻，後續打算支援更多論壇、自行訓練模型並開發瀏覽器套件以內嵌方式分析。
