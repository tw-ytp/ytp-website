**幫不熟悉 3C 操作的人截圖提問、AI 一步步指引**

數位時代的訂票、掃碼點餐等功能為多數人帶來便利，卻困擾不熟悉手機操作的人。HowTo3C 是一個 AI 助手，分桌面與行動兩端。桌面端以 JavaScript、HTML、CSS 做成 WebAPP，結合 PIP 技術讓使用者縮小視窗移到要操作的頁面，截圖處理後給出指示；為保護 API 金鑰，以 Python 在後端架設端點呼叫 Gemini。行動端以 Dart、Kotlin、Swift 實作 Android APP，輸入截圖與問題後教導操作。
