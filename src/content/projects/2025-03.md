**VS Code 擴充：斷點時一鍵把 Linked-list、Graph、Tree 畫成可拖曳的圖**

傳統 Debugger 觀察 Linked-list、Graph、Tree 需手動展開多次，難以看出節點關聯。本系統以 VS Code extension 實作，遇斷點時透過 DAP（Debug Adapter Protocol）取得變數內容，轉為 JSON 後以 Webview 呈現；前後端分離、模塊化，支援 Array、Matrix、Graph、Linked-list、Bar 等呈現模式，以 D3 Drag 與 Node.js 實作可拖曳動圖，並可勾選要顯示的變數。適合教學（二分搜尋、排序、最小生成樹）與程式競賽。已上架 VS Code Marketplace（brinton.cpp-debugger）。
