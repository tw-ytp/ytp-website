## 你在這裡：YTP 年度計畫的三個階段

第一階段程式挑戰營（線上初試 → 現場決賽）各位已完成；今天要談的是中間這一格——**第二階段 YTP2026H2黑客松，12/12 一日賽**；第三階段海外參訪的辦法另行公布。本屆起以黑客松取代過去約半年的專題實作。

## 競賽當日流程（以行前通知為準）

| 時間 | 事項 |
|---|---|
| 08:00 | 報到、設備架設 |
| 09:00 | 開幕・完整賽題公布 |
| 09:30 | 開發開始（業師駐場） |
| 11:30 / 14:30 / 17:00 | 快照 #1 / #2 / #3 |

| 18:40 | 初選：桌邊 Demo 5 分鐘 |

| 20:00 | 決選：Demo＋簡報 8 分鐘 |

快照＝主辦方定時擷取各隊 GitHub Repo，作為 commit 軌跡與真實性驗證的依據。

## 一條紅線：作品主體必須當日完成

- 可以：安裝套件、建立空白專案結構、技術試作（放 `pre-race/` 分支）、研究領域知識。
- 不可以：賽前把已完成的功能程式碼放進 `main`、拿既有作品改名參賽。

## 賽前培訓 E0–E5

共六場、合計約 18 小時（含競賽日全程約 30 小時，平均每週約 2 小時）。只有 E3 與競賽日需要到場；線上場次全程錄影，缺席可補看，E0 錄影 9/4 寄出、其後場次三日內，看完回覆確認回條。家長與老師歡迎旁聽線上場次，不需另外報名。高三同學若因升學時程有特殊考量，請儘早來信 ytp@tw-ytp.org 個別協助。

## GitHub：今年由主辦方幫你建 Repo

主辦方在 GitHub 建立 `ytp26h2` Organization 與各隊專用私有 Repo（隊伍之間互相看不到）。隊長 9/8 前回報每位隊員的 GitHub 帳號，9/15 寄出邀請，9/19 E1 開課前接受（GitHub 邀請 7 天就過期，無法延長）。還沒有帳號請到 github.com/signup 用個人信箱註冊；想看別人怎麼寫，[github.com/26ytph](https://github.com/26ytph) 有上半年得獎作品的完整程式碼。

## 要交的文件（皆於 10/17 截止）

參賽切結書、個資蒐集告知暨同意書、助學金匯款資料（全體隊員）；法定代理人同意書（未成年隊員之家長或監護人）；增補隊員登記含身分證明（隊長代表填寫）。文件與表單於 9/4 一併寄出。AI 工具費用補助核銷則於 12/13–12/20 提交：核銷表格、訂閱憑證（Receipt／Invoice）、後台截圖、刷卡明細（外幣付款必備），檔名須對應。

## 散會後可以做的三件事

1. 跟隊友開一次會：確認誰要參加、要不要補人，缺的是設計、表達還是領域知識。
2. 註冊 GitHub 帳號，9/8 前回報。
3. 加入 Discord，那裡有學長姊幫忙解惑。
